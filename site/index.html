Ask about this repository

Built for people who read the diff.

⌥

Reviewable by default

Every file mutation shows a contextual unified diff with Reject, Allow once, and Always allow. The diff stays in the chat afterward.

⑂

Bounded sub-agents

Two or three read-only investigations run in parallel or as a small dependency graph, each with isolated context and a shared token budget.

◧

Context you can see

A live token indicator, configurable compaction thresholds, and a visible record of every file excerpt and memory item sent to the model.

✎

Project memory

Workspace-scoped facts and decisions you control. Add, edit, disable, or delete them; credential-looking text is rejected on save.

›_

Approved commands

Executables run directly with an argument array, never through an implicit shell, inside the workspace, with timeouts and process-tree cancellation.

⎇

Git-aware

Structured status plus bounded staged and unstaged diffs are available to the agent as read-only tools.

Security is the architecture.

Electron's renderer, preload, and main-process boundary is preserved. The renderer gets a small typed API, never generic IPC or Node.js.

  • API key encrypted with the OS credential store via safeStorage
  • Only key availability is returned to the renderer
  • Saving refuses to overwrite files that changed on disk
  • Deletions are confirmed and bounded to 200 entries / 10 MB
  • Chats and memory stay in local app data

Get started

Requires Node.js 22 or newer.

powershell
PS> git clone https://github.com/sushilbang/code-agent.git
PS> cd code-agent
PS> npm.cmd install
PS> npm.cmd start

Open a folder from the File menu, then add an OpenAI key from the key icon in the agent pane. Local inspection works without a key.
